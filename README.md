# RetailPulse – CDC-Driven Retail Analytics

End-to-end retail analytics platform built using Microsoft Fabric, Azure SQL CDC, Medallion Architecture, and Power BI.

## Architecture

Azure SQL Database
→ Change Data Capture (CDC)
→ Microsoft Fabric
→ Bronze
→ Silver
→ Gold
→ Power BI

## Technologies

- Azure SQL Database
- Microsoft Fabric
- Data Factory
- Lakehouse
- Change Data Capture (CDC)
- Medallion Architecture
- Power BI
- GitHub
